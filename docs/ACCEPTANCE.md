继续验收需要在已登录的 GUI 会话中操作：

```bash
open App/.build/release/qBittorrentX.app
/usr/sbin/screencapture -x -o /tmp/qbx.png
```

截图注意：需要屏幕录制权限；被拒时可能静默返回只有桌面的图片，必须检查图里有没有窗口，不能只看退出码。

建议顺序：先配一台测试用 qBittorrent（或本机假服务器）完成第 5–15 项，再用真实服务器只读验证。写操作仍应遵守 [DEVELOPMENT.md](DEVELOPMENT.md) 的「联调安全边界」。
